# Datheon Python Programming Internship

This repository contains Python projects completed as part of the Datheon Python Programming Internship.

## Task 1: Hangman Game

A simple command-line word guessing game developed using Python.

### Features
- Random word selection
- Letter-by-letter guessing
- Limited incorrect attempts
- Duplicate guess handling
- Win and lose messages

### File
- `hangman.py`

### How to Run
```bash
python hangman.py
```

## Task 2: Investment Portfolio Tracker

A command-line program that records stock purchases and calculates investment performance using sample stock prices.

### Features
- Accepts stock ticker symbols
- Records buying price and share quantity
- Calculates invested amount and current sample market value
- Calculates gain or loss and percentage return
- Exports portfolio records to a CSV file

### Files
- `portfolio.py` — Main Python program
- `portfolio_summary.csv` — Sample portfolio report generated by the program

### Available Sample Tickers
- AAPL
- MSFT
- GOOGL
- AMZN
- TSLA

**Note:** The stock prices are sample values, not live market prices. The CSV report contains test data.

### How to Run
```bash
python portfolio.py
```

## Task 3: Desktop File Organizer

A Python automation utility that organizes files into category-based folders according to their file extensions.

### Features
- Automatically categorizes files by extension
- Creates Documents, Images, Videos, Archives, and Code folders
- Uses `os.scandir()` to inspect files
- Uses `shutil.move()` to move files
- Handles permission errors and naming collisions
- Displays an execution summary with moved, skipped, and failed file counts

### File
- `organizer.py` — Main automation script

### How to Run
```bash
python organizer.py
```

**Note:** The script is configured to use a dedicated test folder. Update the target folder path carefully before organizing any real directory.

### Technologies Used
- Python
- `os`
- `shutil`
- `pathlib`
